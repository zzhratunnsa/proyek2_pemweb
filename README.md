Website ini dirancang untuk mengirim lagu dan pesan secara anonim kepada seseorang. Penerima bisa mencari pesannya dengan mengetik namanya di halaman Jelajahi.

FITUR UTAMA
- Beranda: penjelasan singkat dan 3 langkah penggunaan.
- Kirim Lagu: form dengan validasi dan penghitung karakter, lalu pindah ke halaman Jelajahi.
- Jelajahi: cari berdasarkan nama penerima, urutkan kartu, dan putar lagu (simulasi 30 detik, tanpa suara).

KONSEP JAVASCRIPT
Array of Objects, manipulasi DOM dinamis, event handling (click, input, blur, change, submit), percabangan, perulangan, dan arrow function.

CARA MENJALANKAN
Buka index.html di browser, atau gunakan Live Server di VS Code.

CATATAN
Data hanya tersimpan sementara di memori browser, jadi hilang saat halaman di-refresh.
